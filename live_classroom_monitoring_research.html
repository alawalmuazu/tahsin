Analysis of World-Class Classroom Telemetry Platforms

How industry leaders give teachers eyes across the classroom and how each maps to Tahsin

Nearpod
Formative Presentation
  • Synchronous Slide Push: Facilitator advances presentation slides and student devices follow automatically.
  • Live Participation Matrix: Real-time grid showing student connection state, response status, and submission rates.
  • Real-Time Draw-It & Open-Ended: Live canvas updates showing pupil handwritten answers as they write them.
  • Anonymous Screen Projection: Facilitator shares excellent answers to the room without revealing student identity.
Tahsin Adoption Strategy: Adopt Nearpod's synchronous lesson slide push and live formative matrix, binding each slide directly to Tahsin's schemes_of_work week topics.
GoGuardian Teacher
Device & Screen Supervision
  • Live Screen Carousel: Facilitator sees live updating thumbnails of all pupil screens simultaneously.
  • Tab Visibility & Distraction Audits: Real-time alerts when a student opens unauthorized websites or switches tabs.
  • Focus Mode / URL Lock: Facilitator locks student browsers to specific syllabus URLs.
  • Priority Hand-Raise Queue: Chronological help queue with timestamps.
Tahsin Adoption Strategy: Incorporate browser visibility tracking (document.visibilityState) to flag unfocused/tab-switched students without needing heavy OS agent installs.
ClassDojo
Behavior & Culture
  • Instant Positive Feedback Badges: 1-click sound and visual praise (+1 Fahm, +1 Effort) popping up on student screens.
  • Live Noise Meter & Randomizer: Visual tool keeping classroom calm and selecting students randomly for reciting.
  • Real-time Parent Story Feed: Daily class milestones instantly shared with parents.
Tahsin Adoption Strategy: Build "Tahsin Dojo" into student profiles—rewarding Islamic Akhlaq, Quran accuracy, and active participation with instant WhatsApp notifications to parents.
Pear Deck
Inquiry & Micro-Feedback
  • Live Student Response Stream: Real-time streaming of student typing and drawing answers.
  • Targeted Private Micro-Feedback: Facilitator types a nudge directly onto an individual student's screen.
  • Student-Paced Mode: Allows advanced students to work ahead while teacher monitors progress.
Tahsin Adoption Strategy: Embed private facilitator feedback bubbles directly on student worksheets inside userrole/live_class.
Socrative
Speed & Concept Checks
  • Live Concept Heatmap: Color-coded matrix (Green = Correct, Red = Incorrect, Yellow = In-Progress).
  • Space Race: Gamified team race where correct answers launch rockets across the screen.
  • Instant 1-Click Exit Tickets: Rapid end-of-class comprehension checks.
Tahsin Adoption Strategy: Adopt Socrative's 60-second comprehension check and exit-ticket generator before dismissing classes.
LanSchool (Lenovo)
Classroom Command
  • "Eyes Up" Screen Blanking: 1-click lock that blanks all student screens with an attention banner.
  • Push URL: Simultaneously redirects all connected student browsers to a given page.
  • Battery & Device Status: Warns facilitators when student devices have low battery or poor WiFi.
Tahsin Adoption Strategy: Implement the 1-click "Eyes Up / Pause Screen" lock modal on student dashboards during key facilitator explanations.

Tahsin Live Telemetry Architecture

assets/js/tahsin-pulse.js (Student Telemetry Agent) 
/**
 * Tahsin Academy - Student Live Telemetry Agent
 * Automatically included on student portal live class views.
 * Sends low-overhead status beacons every 5 seconds (< 600 bytes).
 */
(function() {
    const HEARTBEAT_INTERVAL = 5000; // 5 seconds
    let sessionId = window.TAHSIN_LIVE_SESSION_ID || 0;
    let isHandRaised = false;

    function sendPulseBeacon() {
        if (!sessionId) return;

        const payload = {
            session_id: sessionId,
            is_focused: document.hasFocus() && !document.hidden, // Checks active tab state
            current_url: window.location.pathname,
            hand_raised: isHandRaised ? 1 : 0,
            timestamp: Math.floor(Date.now() / 1000)
        };

        fetch(window.BASE_URL + 'userrole/live_pulse', {
            method: 'POST',
            headers: { 'Content-Type': 'application/json' },
            body: JSON.stringify(payload)
        })
        .then(res => res.json())
        .then(data => {
            // If facilitator initiated "Eyes Up" screen lock
            if (data.screen_locked) {
                document.getElementById('eyes-up-modal').style.display = 'flex';
            } else {
                document.getElementById('eyes-up-modal').style.display = 'none';
            }

            // If a merit badge was awarded to this student
            if (data.new_merit) {
                showMeritCelebration(data.new_merit.badge_title, data.new_merit.points);
            }
        })
        .catch(err => console.debug('Telemetry offline', err));
    }

    // Listen for focus changes immediately for real-time reactivity
    window.addEventListener('blur', sendPulseBeacon);
    window.addEventListener('focus', sendPulseBeacon);
    document.addEventListener('visibilitychange', sendPulseBeacon);

    // Background interval heartbeat
    setInterval(sendPulseBeacon, HEARTBEAT_INTERVAL);
})();
application/controllers/Live_session.php (Facilitator Cockpit Controller) 
<?php
defined('BASEPATH') OR exit('No direct script access allowed');

class Live_session extends Admin_Controller {

    public function __construct() {
        parent::__construct();
        $this->load->model('Live_session_model', 'session_model');
        $this->load->model('Scheme_model');
    }

    /**
     * Facilitator Real-time Cockpit View
     */
    public function cockpit($sessionId) {
        $data['session']  = $this->session_model->get_session($sessionId);
        $data['scheme']   = $this->Scheme_model->get_single_scheme($data['session']['scheme_id']);
        $data['students'] = $this->session_model->get_enrolled_students($data['session']['class_id'], $data['session']['section_id']);
        $data['title']    = 'Live Classroom Radar Cockpit';
        
        $this->load->view('layout/index', [
            'sub_page' => 'live_session/cockpit',
            'data'     => $data
        ]);
    }

    /**
     * AJAX endpoint polled by Facilitator UI every 3 seconds for student radar statuses
     */
    public function get_telemetry_radar($sessionId) {
        $radar = $this->session_model->get_active_telemetry($sessionId);
        return $this->output
            ->set_content_type('application/json')
            ->set_output(json_encode(['status' => 'success', 'radar' => $radar]));
    }

    /**
     * 1-Click Award Tahsin Merit Badge to Student
     */
    public function award_merit() {
        $studentId = $this->input->post('student_id');
        $badgeName = $this->input->post('badge_name');
        $points    = (int)$this->input->post('points');
        
        $this->session_model->grant_merit($studentId, $badgeName, $points);
        echo json_encode(['status' => 'success', 'message' => 'Merit awarded!']);
    }

    /**
     * 1-Click Toggle "Eyes Up" Screen Freeze for the Entire Class
     */
    public function toggle_screen_lock($sessionId) {
        $newState = $this->session_model->toggle_lock($sessionId);
        echo json_encode(['status' => 'success', 'screen_locked' => $newState]);
    }
}

Production MySQL Schema Migration

High-performance indexed tables with automatic cleanups and foreign-key ties to Tahsin Core

tahsin_live_telemetry_migration.sql 
-- ====================================================================
-- TAHSIN ACADEMY - LIVE CLASSROOM TELEMETRY & FACILITATOR RADAR SCHEMA
-- ====================================================================

CREATE TABLE IF NOT EXISTS `live_class_sessions` (
  `id` INT AUTO_INCREMENT PRIMARY KEY,
  `branch_id` INT NOT NULL,
  `class_id` INT NOT NULL,
  `section_id` INT NOT NULL,
  `subject_id` INT NOT NULL,
  `scheme_id` INT NULL COMMENT 'Direct relation to schemes_of_work',
  `teacher_id` INT NOT NULL COMMENT 'Staff user ID',
  `session_title` VARCHAR(255) NOT NULL,
  `status` ENUM('active', 'paused', 'ended') DEFAULT 'active',
  `screen_lock` TINYINT(1) DEFAULT 0 COMMENT '1 = Eyes Up screen lock engaged',
  `started_at` DATETIME NOT NULL,
  `ended_at` DATETIME NULL,
  INDEX (`class_id`, `section_id`, `status`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

-- Student Real-time Presence & Focus Telemetry
CREATE TABLE IF NOT EXISTS `live_student_presence` (
  `id` INT AUTO_INCREMENT PRIMARY KEY,
  `session_id` INT NOT NULL,
  `student_id` INT NOT NULL,
  `is_online` TINYINT(1) DEFAULT 1,
  `is_focused` TINYINT(1) DEFAULT 1 COMMENT '0 if window blurred / tab switched',
  `hand_raised` TINYINT(1) DEFAULT 0,
  `current_task_status` VARCHAR(100) DEFAULT 'viewing_lesson',
  `points_earned` INT DEFAULT 0,
  `last_ping` DATETIME NOT NULL,
  UNIQUE KEY `session_student` (`session_id`, `student_id`),
  INDEX (`session_id`, `last_ping`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

-- Formative 60-Second Micro-Polls & Exit Tickets
CREATE TABLE IF NOT EXISTS `live_formative_checks` (
  `id` INT AUTO_INCREMENT PRIMARY KEY,
  `session_id` INT NOT NULL,
  `prompt_text` TEXT NOT NULL,
  `question_type` ENUM('quick_poll', 'multiple_choice', 'open_ended') DEFAULT 'quick_poll',
  `options_json` TEXT NULL,
  `status` ENUM('open', 'closed') DEFAULT 'open',
  `created_at` DATETIME NOT NULL
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

CREATE TABLE IF NOT EXISTS `live_formative_responses` (
  `id` INT AUTO_INCREMENT PRIMARY KEY,
  `check_id` INT NOT NULL,
  `student_id` INT NOT NULL,
  `response_content` TEXT NOT NULL,
  `is_correct` TINYINT(1) NULL,
  `submitted_at` DATETIME NOT NULL,
  UNIQUE KEY `check_student` (`check_id`, `student_id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
